# 🛍️ Modern E-Commerce Shop

A fully functional e-commerce store built with **Vanilla JavaScript**, **Tailwind CSS v4**, and **Vite**.

## 🔗 Live Demo

[**View Live →**](https://your-shop.vercel.app)

## ✨ Features

- 🛒 **Cart** with drawer, quantity control, localStorage
- ❤️ **Wishlist** with badge and dedicated page
- 🔍 **Live Search** with category filter
- 📊 **Sorting** (price, rating, name)
- 📦 **Product Details** with related products
- 💳 **Checkout** with form validation
- 📋 **Order History** with accordion view
- 📱 **Responsive** on all devices
- 💾 **Persistence** via localStorage

## 🛠️ Tech Stack

- Vite
- Tailwind CSS v4
- Vanilla JavaScript (ES6+)
- LocalStorage

## 🚀 Getting Started

```bash
git clone https://github.com/YOUR_USERNAME/shop.git
cd shop
npm install
npm run dev
```
